# Liftlab · Симулятор лифтов

Локальная демонстрация на 52 секунды модельного времени. На 3-м и 8-м этажах одновременно вызывают лифт. Диспетчер назначает B и A. При прохождении шестого этажа кабиной A модель выдаёт событие B1. Кабина тормозит до 16 500 мм и блокируется между этажами. C забирает вызов 8-го этажа с исходным временем регистрации. После перевозки пассажиров следуют диагностика и сброс.

## Посмотреть в браузере

Готовые модель и шкала событий лежат в `viz/out/`. Из корня рабочего дерева, с Node.js 22+ и npm, выполните

```sh
cd viz/viewer
npm ci
npm test
npm run build
npm run dev
```

Откройте адрес `http://127.0.0.1:5173/` или порт из вывода Vite. Нажмите **Запустить**. Кнопки под шкалой переносят к назначению, B1, обслуживанию и диагностике. Стрелки слева от скорости переключают отдельные события, в том числе с одинаковым временем. Нажатие на итог в матрице переключает выделение пар. Для демонстрации используйте **Изометрия**, для сравнения высот — **Фасад**.

## Пересобрать модель и сцену

Из корня рабочего дерева запустите

```sh
python3 -m unittest discover -s viz/blender/sim
python3 viz/blender/sim/model.py
sh viz/blender/scene/build.sh
python3 viz/blender/scene/check.py
```

Python 3.10+ использует стандартную библиотеку. Скрипт запускает Blender 5.2.3 в фоне, экспортирует `scene.glb`, сверяет его с моделью и рендерит три PNG. Путь по умолчанию — `/Applications/Blender.app/Contents/MacOS/Blender`. Для другой установки задайте `BLENDER`. Каталог ресурсов и кеша — `viz/.cache/blender`. Аргумент `--skip-previews` пропускает рендер PNG.

## Контракт данных

`out/timeline.json`, версия 1. Порядок элементов `events` разрешает совпадения времени. Все времена даны в целых мс, положение в мм, скорость в мм/с. Начало координат — пол первого этажа, интервал между этажами 3000 мм.

- `initial`, `calls` задают высоты и исходные вызовы. `events` содержит регистрацию, расчёты, движение, тревогу, блокировку и сброс. `REQUEUE` сохраняет `registeredMs`. Переход в `SERVED` совпадает с полным открытием дверей.
- `DISPATCH` хранит строки, столбцы, ETA, маску допустимости, пары и обе суммы. Ноль в маске запрещает назначение при любой ETA. Пустое значение в матрице обозначает отсутствие ETA. Оптимум перебирает допустимые назначения и выбирает максимум пар, затем минимум суммы. При равенстве приоритет у кабины с меньшим ID, затем у более раннего вызова, затем у меньшего ID вызова. Жадный алгоритм выбирает по расстоянию ближайшую свободную кабину с завершённым циклом дверей. После B1 он не назначает ни одной пары, а оптимум может зарезервировать C с учётом оставшегося ожидания.
- `motions` хранит интервалы движения и фазы разгона, равномерного движения и торможения. Фаза задаёт длительность, смещение, путь и две скорости. Интеграл округляется к ближайшему мм, половины от нуля. В TypeScript для произведений используется `BigInt`. `golden.json` содержит общие эталонные точки. `doors` задаёт этаж, интервал и долю открытия от 0 до 1000.
- Для другой панели достаточно импортировать `parseTimeline` из `viewer/src/timeline.ts` и `stateAt` из `viewer/src/player.ts`. Вызов `stateAt(timeline, tMs)` возвращает кабины, двери, вызовы, тревогу и матрицу. Третий аргумент выбирает конкретное событие в группе. Эти модули обходятся без DOM и Three.js.

## Допущения

В `config.json` параметры **примерные**. Предел скорости 3000 мм/с, ускорение 1500 мм/с², экстренное замедление 3000 мм/с². Профиль трапецеидальный или треугольный, без ограничения рывка. Ход дверей занимает 2,4 с, выдержка 5 с. A стартует на 4-м этаже, B на 1-м, C на 10-м с открытыми дверями и остатком выдержки 16 с. Для завершения демонстрации пассажиры едут на 1-й и 10-й этажи. Начальная сумма ETA составляет 10 с у оптимума и 11,828 с у жадного выбора. Прототип воспроизводит события локально. Источник истины для настоящего контроллера — Rust workspace.
