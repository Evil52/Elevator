# Elevator · Симулятор лифтов

Просмотрщик воспроизводит две локальные записи. В Rust SIL кабина A совершает поездку с 1-го на 4-й этаж. Демонстрация отказа B1 занимает 52 секунды модельного времени. На 3-м и 8-м этажах одновременно вызывают лифт. Диспетчер назначает B и A. При прохождении шестого этажа кабиной A модель выдаёт событие B1. Кабина тормозит до 16 500 мм и блокируется между этажами. C забирает вызов 8-го этажа с исходным временем регистрации. После перевозки пассажиров следуют диагностика и сброс.

## Посмотреть в браузере

Общая 3D-сцена и запись B1 лежат в `viz/out/`. Запись Rust SIL находится в `viz/recordings/single-trip/timeline.json`. Рядом лежит [скриншот интерфейса](out/preview-interface.png). Из корня рабочего дерева, с Node.js 22+ и npm, выполните

```sh
cd viz/viewer
npm ci
npm test
npm run build
npm run dev
```

Откройте адрес `http://127.0.0.1:5173/` или порт из вывода Vite. Нажмите **Запустить**. Кнопки под шкалой переносят к назначению, B1, обслуживанию и диагностике. Стрелки слева от скорости переключают отдельные события, в том числе с одинаковым временем. Нажатие на итог в матрице переключает выделение пар. Для демонстрации используйте **Изометрия**, для сравнения высот — **Фасад**.

## Одна поездка Rust SIL

В меню сценария выберите **Открыть поездку Rust SIL**. Прямая ссылка — [поездка SIL](http://127.0.0.1:5173/?scenario=sil). Кнопки под шкалой останавливают показ на контрольных точках. В телеметрии A указана высота в миллиметрах.

| Событие | Модельное время | Высота A |
|---|---:|---:|
| Разгон | 1,250 с | 766 мм |
| Постоянная скорость | 2,750 с | 4 500 мм |
| Торможение | 4,250 с | 8 234 мм |
| Остановка, `ARRIVED` | 5,500 с | 9 000 мм |
| Двери полностью открыты, `SERVED` | 7,900 с | 9 000 мм |

Кабины B и C в этом прогоне находятся в резерве. Матрицу и назначение рассчитывает `elevator-ctrl`. Для A заданы пределы 3000 мм/с, 1500 мм/с² и 3000 мм/с³. Один план S-кривой задаёт время остановки и координаты. Экспортёр сохраняет узлы каждые 50 мс. На узлах положение и скорость в проигрывателе совпадают с Rust. При сверке всех 5501 целых миллисекунд этой поездки максимальное расхождение между узлами составило 1 мм по положению и 2 мм/с по скорости.

Пересоздать запись из корня репозитория можно так

```sh
trip=viz/recordings/single-trip/timeline.json
cargo run --quiet --locked -p elevator-sil > "$trip.tmp" && mv "$trip.tmp" "$trip"
cargo test --locked -p elevator-sil
```

Тест сверяет вывод программы с файлом просмотрщика побайтно. Просмотр готовой записи требует только Node.js.

## Пересобрать модель и сцену

Из корня рабочего дерева запустите

```sh
python3 -m unittest discover -s viz/blender/sim
python3 viz/blender/sim/model.py
sh viz/blender/scene/build.sh
python3 viz/blender/scene/check.py
```

Python 3.10+ использует стандартную библиотеку. Скрипт запускает Blender 5.2.3 в фоне, экспортирует `scene.glb`, сверяет его с моделью и сохраняет три PNG ключевых событий в `viz/.cache/previews/`. Аргумент `--out DIR` направляет GLB и эти кадры в указанный каталог. Путь по умолчанию — `/Applications/Blender.app/Contents/MacOS/Blender`. Для другой установки задайте `BLENDER`. Каталог ресурсов и кеша — `viz/.cache/blender`. Аргумент `--skip-previews` пропускает рендер PNG.

## Источник расчётов

Запись с отказом B1 создаёт демонстрационный генератор Python. Он использует трапецеидальный или треугольный профиль и оценивает прямой путь до остановки. На матрице указано происхождение этих ETA.

Эталон поведения лифтовой группы — Rust-ядро. Экспортёр `sil/` использует его для одной поездки. Полный групповой сценарий с отказом и переназначением пока воспроизводится из записи Python.

## Контракт данных

`out/timeline.json`, версия 1. Поле `source` указывает генератор. Демо записывает `python-demo`, Rust SIL записывает `rust-sil`. У старых записей источник может отсутствовать. Порядок элементов `events` разрешает совпадения времени. Все времена даны в целых мс, положение в мм, скорость в мм/с. Начало координат — пол первого этажа, интервал между этажами 3000 мм.

- `initial`, `calls` задают высоты и исходные вызовы. `events` содержит регистрацию, расчёты, движение, тревогу, блокировку и сброс. `REQUEUE` сохраняет `registeredMs`. Переход в `SERVED` совпадает с полным открытием дверей. Конечный `END` удерживает последний кадр, а `RESET` возвращает кабины на старт.
- `DISPATCH` хранит строки, столбцы, ETA, маску допустимости, пары и обе суммы. Ноль в маске запрещает назначение при любой ETA. Пустое значение в матрице обозначает отсутствие ETA. Оптимум перебирает допустимые назначения и выбирает максимум пар, затем минимум суммы. При равенстве приоритет у кабины с меньшим ID, затем у более раннего вызова, затем у меньшего ID вызова. Жадный алгоритм выбирает по расстоянию ближайшую свободную кабину с завершённым циклом дверей. После B1 он не назначает ни одной пары, а оптимум может зарезервировать C с учётом оставшегося ожидания.
- `motions` хранит интервалы движения и фазы разгона, равномерного движения и торможения. Фаза задаёт длительность, смещение, путь и две скорости. Интеграл округляется к ближайшему мм, половины от нуля. В TypeScript для произведений используется `BigInt`. `golden.json` содержит общие эталонные точки. `doors` задаёт этаж, интервал и долю открытия от 0 до 1000.
- Для другой панели достаточно импортировать `parseTimeline` из `viewer/src/timeline.ts` и `stateAt` из `viewer/src/player.ts`. Вызов `stateAt(timeline, tMs)` возвращает кабины, двери, вызовы, тревогу и матрицу. Третий аргумент выбирает конкретное событие в группе. Эти модули обходятся без DOM и Three.js. Blender использует общий читатель `blender/sim/playback.py`. Профиль v1 описывает линейное изменение скорости внутри фазы. Между узлами SIL этот профиль интерполирует записанный участок S-кривой.

## Параметры демо B1

В `config.json` параметры **примерные**. Предел скорости 3000 мм/с, ускорение 1500 мм/с², экстренное замедление 3000 мм/с². Профиль трапецеидальный или треугольный, без ограничения рывка. Ход дверей занимает 2,4 с, выдержка 5 с. A стартует на 4-м этаже, B на 1-м, C на 10-м с открытыми дверями и остатком выдержки 16 с. Для завершения демонстрации пассажиры едут на 1-й и 10-й этажи. Эта выставочная расстановка даёт 10,0 с у оптимума и 11,828 с у жадного выбора. Для контрольной расстановки в [ТЗ проекта](../README.md) приведены отдельные примерные суммы 11,03 с и 29,4 с. Каждую пару чисел следует читать в контексте своего сценария.
